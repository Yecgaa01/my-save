 # My-Save

Make Steam backups and access the game's folders directly from the game page in the Library

This is a plugin for [Millennium](https://steambrew.app/), therefore it is required.

# Installation

* This guide assumes you already have Millennium installed. If you don't have it yet and wish to install it, visit the [Millennium page](https://docs.steambrew.app/users/getting-started/installation).



Click on the green button labeled "Code" and click "Download ZIP".

![Step 1](https://i.imgur.com/ZWbw6Oa.png)

On Steam, click on Steam -> Millennium -> Plugins and select "Browse local files".

![Step 2](https://i.imgur.com/g6PDMVx.png)
![Step 3](https://i.imgur.com/TvTg428.png)
![Step 4](https://i.imgur.com/QShTOnw.png)

Open the ZIP you downloaded and drag the `my-save` folder to the folder you just opened in Millennium (usually `Steam\millennium\plugins`).

![Step 5](https://i.imgur.com/zG8g7CH.png)

After that, go back to Steam (you might need to click on another tab in Millennium, like "Updates", and click on "Plugins" again for My-save to appear). Enable it and click "Save changes" at the top of the page. It will prompt Steam to restart.

![Step 6](https://i.imgur.com/JVl6B7u.png)
![Step 7](https://i.imgur.com/R2kUeud.png)
![Step 8](https://i.imgur.com/Um4I1BR.png)

After that, go to any game's page and look for the floppy disk icon in the bottom right corner of the game banner. If it's there, it worked (yay!) And then the testing begins. In my opinion, everything is very intuitive in the plugin and you shouldn't have much trouble using it, but if you have any questions, feel free to ask.

![Step 9](https://i.imgur.com/9ZSqt7g.png)
![Step 10](https://i.imgur.com/Ywisvhu.png)

You can create a single backup (which overwrites the previous one whenever the backup is made), or create multiple backups every time the "Backup" button is pressed. You can view the backup, the date and time it was made, and even restore it, all without leaving the game page. You can also choose the folder where these backups will be saved.

![Step 11](https://i.imgur.com/qVfLJTw.png)
